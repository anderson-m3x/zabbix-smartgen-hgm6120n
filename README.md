# Zabbix template: SmartGen HGM6120N / HGM6120NC (Modbus TCP)

Шаблон Zabbix 7.x для контроллера генераторной установки **SmartGen HGM6120N/NC**: 43 метрики
и 14 триггеров, снятых и расшифрованных с живого контроллера по Modbus TCP.

Всё, что в шаблоне, проверено на работающем генераторе: карта регистров собрана опросом
`modbus.get` (функции 01 и 03), единицы и масштабы сверены с показаниями на панели
контроллера, пороги давления масла — с мануалом двигателя 6105.

## Что внутри

| Файл | Что это |
|---|---|
| `template_smartgen_hgm6120n.json` | сам шаблон (формат экспорта Zabbix 7.4) |
| `registers.md` | карта регистров: адрес, функция, тип, единицы, период опроса |

Состав шаблона:

- **43 item'а**: напряжения сети и генератора (фазные и линейные), частоты, токи, активная,
  реактивная и полная мощность, коэффициент мощности, давление масла, температура ОЖ, уровень
  топлива, обороты, напряжение АКБ и D+, наработка (моточасы), статусы автоматики
  (авто/ручной/стоп), общая авария, аварийный останов, «пропало напряжение сети»;
- **14 триггеров** с восстановлением;
- **value maps** для битовых статусов (например, `Common Alarm Status`);
- вычисляемый item «Maintenance Summary» — сводка по наработке и срокам ТО.

## Как это работает

```
Zabbix server ──► Zabbix agent (машина, откуда виден контроллер) ──► Modbus TCP:502 ──► HGM6120N
```

`modbus.get` — проверка **Zabbix-агента**, а не сервера. Поэтому у хоста в Zabbix должен быть
интерфейс типа *Zabbix agent* с адресом машины, на которой запущен агент и с которой доступен
контроллер. В нашем случае агент стоит на самом сервере Zabbix, поэтому интерфейс `127.0.0.1:10050`.

## Установка

1. `Data collection → Templates → Import` → выбрать `template_smartgen_hgm6120n.json`.
   Импорт создаёт группу `Templates`, если её нет (правило «Create missing» включено по умолчанию).
2. Создать хост, интерфейс — *Zabbix agent* (адрес машины с агентом), привязать шаблон
   *SmartGen HGM6120N genset controller (Modbus)*.
3. Задать макросы на хосте (или на шаблоне):

| Макрос | По умолчанию | Смысл |
|---|---|---|
| `{$HGM.HOST}` | `192.168.1.10` | IP контроллера |
| `{$HGM.PORT}` | `502` | TCP-порт Modbus |
| `{$HGM.SLAVE}` | `1` | Modbus slave ID |

Остальные макросы — пороги триггеров, см. таблицу ниже.

4. Проверить связность с машины агента: `nc -zv <IP контроллера> 502`.
5. Подождать 1–2 минуты: item'ы опрашиваются раз в минуту.

## Макросы порогов

| Макрос | Значение | Смысл |
|---|---|---|
| `{$HGM.RPM.RUNNING}` | `500` | Обороты, выше которых двигатель считается работающим |
| `{$HGM.OIL.LOW}` | `250` кПа | Давление масла ниже — проблема |
| `{$HGM.OIL.LOW.REC}` | `300` кПа | Восстановление |
| `{$HGM.OIL.HIGH}` | `800` кПа | Давление выше — проблема (упор в редукционный клапан) |
| `{$HGM.OIL.HIGH.REC}` | `700` кПа | Восстановление |
| `{$HGM.TEMP.HIGH}` | `95` °C | Температура ОЖ |
| `{$HGM.TEMP.HIGH.REC}` | `90` °C | Восстановление |
| `{$HGM.FUEL.LOW}` | `30` % | Уровень топлива |
| `{$HGM.FUEL.LOW.REC}` | `50` % | Восстановление |
| `{$HGM.BATT.LOW}` | `25` В | Напряжение АКБ |
| `{$HGM.BATT.LOW.REC}` | `25.5` В | Восстановление |
| `{$HGM.GEN.VOLTAGE}` | `180` В | Генератор выдаёт напряжение |
| `{$HGM.GEN.VOLTAGE.REC}` | `50` В | Восстановление |

## Триггеры

| Триггер | Важность | Условие |
|---|---|---|
| Аварийное отключение генератора | Disaster | `Common Shutdown = 1` |
| Нажата кнопка аварийного останова | Disaster | `Emergency Stop = 1` или `Emergency Stop Input = 1` |
| Контроллер генератора недоступен | Disaster | `nodata(fuel level, 5m)` |
| Общая авария генератора | High | `Common Alarm = 1` |
| Низкое давление масла | High | `max(масло, 3m) < {$HGM.OIL.LOW}` и `min(обороты, 3m) > {$HGM.RPM.RUNNING}` |
| Высокая температура охлаждающей жидкости | High | `>= {$HGM.TEMP.HIGH}` |
| Генератор не в авторежиме | High | `In Manual Mode = 1` |
| Генератор в режиме СТОП | High | `In Stop Mode = 1` |
| Пропало напряжение сети | Warning | `Mains OK = 0` |
| Низкий уровень топлива | Warning | `< {$HGM.FUEL.LOW}` |
| Низкое напряжение аккумулятора | Warning | `< {$HGM.BATT.LOW}` |
| Высокое давление масла | Warning | `min(масло, 3m) > {$HGM.OIL.HIGH}` и `min(обороты, 3m) > {$HGM.RPM.RUNNING}` |
| Генератор взял нагрузку | Info | `Gen On-load = 1` |
| Генератор запустился и выдаёт напряжение | Info | `Gen Ua > {$HGM.GEN.VOLTAGE}` |

## Почему триггеры по маслу выглядят именно так

Это самая полезная часть работы, и без неё шаблон шумит.

1. **Давление масла и обороты опрашиваются разными item'ами и приходят в разные секунды**
   (у нас — `:47` и `:49` каждой минуты). В минуту остановки масло уже отдаёт 0, а у оборотов
   ещё лежит значение прошлой минуты. Условие «давление низкое **и** двигатель работает»
   выполняется ровно один такт — и на каждой остановке появляется ложная авария.
   Лечение: окно **3 минуты** — `max(oil, 3m) < порог` и `min(rpm, 3m) > порог`. Одиночный
   рассинхронизированный такт такое условие не выполняет.
2. **Восстановление должно учитывать остановку двигателя.** Если в выражении восстановления
   только давление (`oil >= 300`), то при стоящем генераторе (0 кПа) оно никогда не выполнится,
   и проблема висит открытой до следующего пуска. Поэтому в recovery добавлено
   `или rpm <= {$HGM.RPM.RUNNING}`.
3. **Почему «высокое давление» — это 800 кПа.** Норма по мануалу двигателя 6105
   (MMR4-6105, §1.4) — 0.3–0.55 МПа на номинале, на холостом ходу ≥0.1 МПа; редукционный
   клапан открывается при 0.8 МПа (§9.2). Порог 650 кПа (6.5 бар) попадает внутрь рабочего
   диапазона и на холодном масле горит постоянно. Порог 800 кПа означает «давление упёрлось
   в клапан и держится там три минуты» — это уже неисправность.

Подробный разбор с цифрами: `oil-pressure-2026-11-11.md` во внутреннем репозитории автора,
в публичной версии — раздел выше.

## Ограничения

- Проверено на **HGM6120N**; у **HGM6120NC** карта регистров может отличаться прошивкой.
  Если значения не совпадают — сверяйте с `registers.md` и протоколом SmartGen.
- Единицы и масштабы — как отдаёт контроллер (давление в кПа, обороты в об/мин). Датчики
  не калибруются шаблоном: если показания расходятся с механическим манометром, правьте
  кривую датчика в настройках контроллера, а не пороги в Zabbix.
- `modbus.get` поддерживается Zabbix 5.0+; шаблон экспортирован из 7.4. Для 6.x поменяйте
  `"version"` в JSON (обычно достаточно `6.0`) — структура совместима.
- Триггеры ссылаются на item'ы по ключу с макросами (`tcp://{$HGM.HOST}:{$HGM.PORT}`):
  при правке ключа в шаблоне поправьте и выражения.
